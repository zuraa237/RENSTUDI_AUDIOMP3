RENSTUDIO AUDIO EDITOR V4

FITUR:
- UI RENSTUDIO dark red/cyan mengikuti background artwork.
- Open MP3/WAV
- Waveform + seek
- Trim start/end
- Speed 0.25x–4x
- Pitch -12..+12 semitone
- Volume + pan
- Bass/treble
- Fade in/out
- Loop
- Export WAV
- Export MP3 (encoder CDN saat pertama dipakai)
- Import YouTube/TikTok melalui backend yt-dlp + FFmpeg

WINDOWS:
1. Install Python 3.10+.
2. Install FFmpeg dan pastikan perintah ffmpeg bisa dipanggil dari CMD.
3. Jalankan START_WINDOWS.bat.
4. Buka http://127.0.0.1:8787

CATATAN:
Import link membutuhkan backend. Jangan membuka index.html dengan double-click jika ingin fitur link.
Gunakan hanya audio yang boleh kamu unduh/edit.
